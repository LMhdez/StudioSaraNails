# Studio Sara Nails

Aplicação web para gestão de um estúdio de unhas. O código da aplicação está na pasta `StudioSaraNails/`.

## Conteúdo

- `StudioSaraNails/` — aplicação React com Vite.
- `StudioSaraNails/src/pages/` — páginas de início, serviços, agenda, autenticação, recuperação de palavra-passe e área de administração.
- `StudioSaraNails/src/components/` — formulários, calendário, componentes de serviços e elementos de interface.

## Começar

Consulta o [README da aplicação](StudioSaraNails/README.md) para os comandos de instalação, desenvolvimento, validação e build.

## Segurança

Não adicionar credenciais, tokens, palavras-passe, chaves privadas ou ficheiros de configuração locais ao Git. Configurações de serviços externos devem usar apenas os valores públicos apropriados no frontend e políticas de acesso corretamente configuradas no serviço.
